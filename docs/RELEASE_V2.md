# Release V2 · 2026-10-23

## Requested changes
1. Slower default pace and prolonged encounter scenes.
2. 2–4 animated stick figures to depict movements, attack/defense, escapes and the actual elimination outcome.
3. Increase the selectable roster from 252 to **500** athletes. Each match still contains **12** contestants.

## Verification
- 500 unique profiles and 500 signature perks across 16 sports.
- 81 headless scripted tests complete with 11 distinct standard-roster winners.
- 465 combat eliminations versus 415 zone eliminations across the 80 seed suite.
- 390px Chromium run confirmed 500 draft choices, animated three-person clash, one champion and no horizontal overflow or page exceptions.

## Caveats
Ratings, behavioral traits and uniforms are provisional; the representation is entertainment, not a validated prediction of real-world athletes. Commercial rights require review. Some interaction text and choreography are simplified V2 game mechanics, not physics animation.
