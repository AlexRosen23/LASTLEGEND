# V23–V25 local competitive tools

- V23: actually simulated deterministic single-elimination tournaments with 4/8/16/32/64 unique drafted athletes; view winners by round.
- V24: common UTC daily seed and consistent 12-player selection for a fixed roster version. Not ranked globally.
- V25: bookmark replay frames, jump to important events, export local JSON with recorded frames and events. It does not provide hosted/cloud replays.
