# V16: Gameplay win-share laboratory

In the Draft, 2–12 selected competitors can run 16 seeded simulation trials. The on-device lab counts wins, mean placement and mean eliminations, recording the seed and arena/mode assumptions. It runs asynchronous chunks on the user's browser and never changes the current match. It is a sample of fictional game behavior, not real-world statistical forecasting, a backend leaderboard, or comprehensive replay analytics.
